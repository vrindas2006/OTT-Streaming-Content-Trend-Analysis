# OTT Streaming Content Trend Analysis

## 📌 Project Overview

This project analyzes Netflix streaming content trends using Python, SQL, and data visualization.

The analysis explores content types, genres, countries, ratings, content addition trends, release years, and movie duration. The project also converts the analysis into actionable content strategy recommendations.

This project was completed as part of my **Veda Technology Data Analytics Internship/Project**.

---

## 🎯 Objectives

- Analyze Netflix content using Python and SQL.
- Identify trends in Movies and TV Shows.
- Explore popular genres and countries.
- Analyze content addition trends over the years.
- Examine rating distribution.
- Calculate average movie duration.
- Analyze content release-year trends.
- Generate actionable content strategy recommendations.

---

## 📊 Dataset

**Dataset:** Netflix Movies and TV Shows

**Source:** Kaggle

**Number of Titles:** 8,807

The dataset contains information such as:

- Show ID
- Type
- Title
- Director
- Cast
- Country
- Date Added
- Release Year
- Rating
- Duration
- Listed In / Genres
- Description
